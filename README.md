# LumiVocab Adventure v2.1

英検級別に分けた、イラスト・音声・クイズ・間隔反復型のオフライン対応Webアプリです。

## 収録コース

- 子ども用：英検3級 900語
- 子ども用：英検準2級 1,100語
- 子ども用：英検2級 1,300語
- 大人用：英検準1級 1,600語
- 大人用：英検1級 2,100語
- 合計：7,000語

各級のJSONは個別ファイルです。

- `words-grade3.json`
- `words-pre2.json`
- `words-grade2.json`
- `words-pre1.json`
- `words-grade1.json`
- `words-all.json`（全級まとめ）

`word-packs.js` は、ローカルファイルとして開いた場合にも動作させるための実行用データです。

## v2.1の主な変更

- 子ども用／大人用を分けた級別コーナー
- 英検3級から1級まで、合計7,000語へ増量
- 各級を重要度A・B・Cに内部分類
- ホーム、冒険、対戦、単語帳、記録を選択中の級に連動
- 各単語に意味カテゴリに応じたオリジナルSVGイラストを自動描画
- クイズの回答後、「次の問題へ」を画面下部に常時表示
- 問題部分だけを内部スクロールにし、次ボタンまでページ全体をスクロールする必要を解消
- iPhoneでは選択肢を常に2列表示
- 画面が低い端末ではイラストと余白を自動縮小
- 単語帳は120語ずつ順次表示して動作負荷を軽減
- 級別の学習数・習得数・定着率を保存
- PWA／オフラインキャッシュ対応

## GitHub Pagesへの公開

推奨リポジトリ名：`lumi-vocab-adventure`

1. ZIPを解凍します。
2. 現在のリポジトリ内の古いファイルを、解凍後の新しいファイルですべて置き換えます。
3. 解凍後に現れるファイルを、すべてリポジトリの最上位へアップロードします。
4. ZIPそのものはアップロードしません。
5. GitHubの `Settings → Pages` で、`Deploy from a branch`、`main`、`/(root)` を選択します。

すべての公開ファイルが同じ階層にあるため、iPhoneからアップロードしてもフォルダ構造が崩れません。

## データについて

本データは英検協会や市販教材の公式単語一覧を複製したものではありません。公開辞書の語義、試験カテゴリ、英語コーパス頻度を組み合わせ、本アプリ用の独自練習語彙として級分けしています。詳細は `DATA-SOURCES.md` を参照してください。
